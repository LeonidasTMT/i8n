# 01. docs — project documentation

Project-level documentation: pipeline doc (how this build was made), build
runbook, standard-adaptation doc, and the doctrine copies.

- **Goes here:** `TRANSLATION.md` + `WORKSPACE.md` (copied from the i8n
  library at instantiation), engine-specific pipeline doc, build runbook,
  any adaptation plan for the workspace standard.
- **Doesn't go here:** scratch notes (`work/`), per-stage reports
  (`03. extraction/`), test evidence (`06. testing/`).
